# 🌱 Peaceful Life Finance Tracker

A lightweight, single-file web application designed to help individuals track their monthly income, categorize expenses, avoid overspending, and maintain long-term financial stability.

---

## 📌 Project Overview

Managing personal finances can often feel overwhelming. The **Peaceful Life Finance Tracker** simplifies money management by offering clear, visual feedback on your monthly habits. By incorporating the proven **50/30/20 Budgeting Rule**, the application gives you an actionable plan to keep your lifestyle stress-free and within your financial means.

---

## ✨ Key Features

* **50/30/20 Budgeting Rule**: Automatically calculates targets for:
* **Needs (50%)**: Groceries, Healthcare, Educational Bills.
* **Wants (30%)**: Trips, Shopping, Entertainment.
* **Savings & Debt (20%)**: Investments and Loan Payments.


* **Overboard Alerts**: Triggers real-time warning banners and visual indicators if your spending exceeds your salary or category limits.
* **Smart Financial Suggestions**: Analyzes your monthly spending patterns and offers tailored tips to optimize your budget.
* **Local Data Persistence**: Saves all salary and expense data directly in your browser (`localStorage`) so your private data never leaves your device.
* **No Server Required**: Runs completely offline using a single HTML file.

## 🚀 How to Run the App Locally

1. **Clone the repository**:
```bash
git clone https://github.com/adilhannan20-byte/Finance-tracker.git

```


2. **Open the project folder**:
```bash
cd Finance-tracker

```


3. **Launch the application**:
* Double-click the `index.html` file to open it in any web browser (Chrome, Firefox, Edge, Safari).
* Or, use the **Live Server** extension inside VS Code.
